# 会话历史恢复记录

> 本文记录一次已定位问题的通用恢复原则，不包含本机目录、会话标识、扫描报告或其他私人运行数据。面向用户的安全操作步骤见[历史恢复指南](<session-history-recovery-guide.md>)。

## 问题与修复

插件曾向宿主会话日志追加宿主不认识且未标记为可忽略的私有事件。严格重放时遇到未知必需事件，可能导致历史会话无法加载。不要因此删除会话日志，也不要关闭宿主的未知事件校验。

插件已停止向会话日志追加私有用量事件；实时用量仅用于运行时显示，持久账本由插件自己的 usage journal 管理。离线日志恢复工具只对明确列出的 Maestro 元数据事件补充 `ignorable: true`，不会删除事件、修改聊天正文或扩大对其他未知类型的忽略范围。

## 安全边界

- 对真实日志进行修复前，完全退出所有 DSH 进程，并使用正式指南中的扫描、备份、校验及原子替换流程。
- 先在合成日志副本上验证编解码和修复逻辑；只读预演和测试通过不代表真实日志已恢复。
- 逐个备份并校验待修改文件。遇到未知事件、哈希不匹配、备份冲突或部分失败时停止，保留原始数据并寻求维护者协助。
- 不公开上传包含会话正文、凭据、真实会话标识或个人目录的日志、备份和诊断报告。

## 相关实现

历史日志编解码器和扫描/恢复脚本位于 `scripts/`。当前可修复的事件类型由编解码模块中的白名单定义；任何新增类型都必须先确认其语义和兼容性，再更新对应测试与文档。
